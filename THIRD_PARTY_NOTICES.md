# Third-party software

This repository contains an adapter written for the public Java API of
[Logisim-evolution 3.9.0](https://github.com/logisim-evolution/logisim-evolution/tree/v3.9.0).
Logisim-evolution is a separate GPL-3.0 project; its source and binary JAR are not
included in this repository or the release archive. Download it separately from
the project's official release page and retain its own license and notices.

Node.js and the Java runtime/JDK are separately installed prerequisites. No
third-party npm packages or user-provided course manuals are bundled.
